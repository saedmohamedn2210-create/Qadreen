# Qadreen (قادرين)

An add-on developed to serve the Qadreen community. This add-on enables supervisors and users to manage and organize their links quickly and effectively through adding, copying, opening, organizing, and fully sharing them with high speed and efficiency. The add-on can be discovered via the shortcut Insert+Ctrl+H.

## Features
- Fast link management and organization.
- Instant access via global shortcut `NVDA+Control+H`.
- Designed for optimal accessibility with screen readers.
